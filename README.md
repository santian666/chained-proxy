# VPS Sing-box 节点管理服务端 (Go 精简版)

专为 Linux VPS 服务器打造的极简、轻量、高性能 `sing-box` 节点管理工具（基于 Go 纯标准库开发，无外部依赖）。

---

## ⚡ 一键极速安装 / 运行

在任何一台 Linux VPS（Ubuntu / Debian / CentOS / Alpine 等，支持 AMD64 与 ARM64）上，以 `root` 用户运行以下单行命令即可直接安装并打开菜单：

```bash
curl -fsSL https://raw.githubusercontent.com/santian666/vps-management/main/install.sh | bash
```

安装后，无论在哪个目录下，只要在终端输入：
```bash
vps
```
即可随时秒进管理菜单！

---

## 🚀 核心特性

1. **最新版内核自动部署**：启动时自动检测并升级至 GitHub 官方最新正式版 `sing-box` 内核，自动配置 BBR 加速与 AnyTLS 自签名证书。
2. **四重日志与缓存防爆盘保护**：
   - 限制 JSON 日志级别为 `warn`；
   - 强制限制 Systemd Journal 日志上限为 `50MB`；
   - 部署 Logrotate 10MB 自动截断；
   - 部署后台定时清理守护任务（每 2 小时自动截断超限日志并清理 3 天前缓存与临时文件），彻底杜绝磁盘被日志塞满。
3. **全功能执行后自动重启**：无论执行哪个菜单功能，最后均自动执行清理缓存、`sing-box check` 校验及服务重启，确保状态实时生效。
4. **命名与标准交付格式**：
   - **Direct 直连节点**：以 `本机IP` 作为协议名，输出 `本机IP----协议链接`。
   - **SOCKS5 出站节点**：以 `SOCKS5的IP` 作为协议名，输出 `完整socks5----协议链接`。
   - **按次时间戳独立留存**：每次操作仅将当次操作涉及的节点保存至 `/root/nodes_<动作>_YYYYMMDD_HHMMSS.txt`。

## 📋 功能菜单说明

```text
====================================================================
              VPS Sing-box 节点管理 (服务端最新版)
  本机主IP: 1.2.3.4 (共 3 个公网IP) | 内核: v1.12.x
  服务状态: 运行中 (active)         | 当前节点数: 12
====================================================================
  1. 新增节点
  2. 新增多IP节点 (纯直连)
  3. 修改落地 (按IP匹配更新 SOCKS5 端口/账号/密码)
  4. 节点列表
  5. 配置编辑
  6. 删除节点
  0. 退出 (输入 0 或 7 退出)
====================================================================
```

* **1. 新增节点**：
  * 入站协议支持 3 种：`VLESS + Reality`、`AnyTLS`、`SOCKS5`（自动生成 8 位随机账密）。
  * 出站协议仅限 2 种：`Direct（直连）`、`SOCKS5（落地）`（内置 1.5 秒并发快速连通性验活）。
* **2. 新增多IP节点**：
  * 自动扫描网卡所有公网 IPv4，支持筛选未建节点 IP，固定为 `Direct` 且严格绑定对应出口 IP（源进源出）。
* **3. 修改落地**：
  * 专用于出站为 SOCKS5 的节点。直接粘贴新 SOCKS5，按 IP 自动匹配并原地更新端口、账号、密码，原入站节点协议、端口、UUID/密码与分享链接 100% 保持不变。
* **4. 节点列表**：
  * 列表格式：`节点序号---节点IP----协议`。支持一键导出当前服务器全部节点的标准格式结果。
* **5. 配置编辑**：
  * 醒目提示编辑器操作快捷键（`nano` 的 `Ctrl+O` 保存、`Ctrl+X` 退出），退出后自动校验语法，若改错自动拦截并提供回滚保护。
* **6. 删除节点**：
  * 支持输入节点序号（如 `1`、`1-5`）或输入 IP（本机 IP 或 SOCKS5 落地 IP）快速批量删除。

## 🛠️ 自行源码编译

项目使用纯 Go 标准库编写（Go 1.20+），无需拉取外部第三方包：

```bash
# 编译 Linux AMD64
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath -ldflags="-s -w" -o bin/vps .

# 编译 Linux ARM64
CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -trimpath -ldflags="-s -w" -o bin/vps-arm64 .
```
